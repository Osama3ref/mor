# مور — تطبيق أندرويد

بيلعبوا أربعة على نفس الواي فاي (أو هوتسبوت جوال المضيف)، بدون إنترنت وبدون حسابات.

## كيف تطلع ملف APK
1. اعمل مستودع جديد على GitHub وارفع محتوى هالمجلد كما هو (لازم يكون فيه المجلد `.github`).
2. GitHub بيبني التطبيق لحاله خلال 3 لـ 5 دقايق (تبويب Actions).
3. من صفحة المستودع، قسم **Releases** ← `Mor APK` ← نزّل `Mor.apk` على الجوال وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

لتحديث اللعبة: بدّل `app/src/main/assets/index.html` وارفعه، وبيطلع APK جديد لحاله.

## اللعب
- المضيف بيفتح التطبيق ← «استضيف غرفة» ← بيطلعله عنوان متل 192.168.1.5.
- الباقيين بيكتبوا العنوان بالتطبيق، أو بيفتحوا `http://192.168.1.5:8765` بمتصفح الجوال إذا ما عندهم التطبيق.
- خلّوا التطبيق مفتوح عند المضيف طول اللعبة.

ملاحظة: كل بناء جديد بيطلع بتوقيع جديد، فلتثبّت نسخة أحدث امسح القديمة أول.
